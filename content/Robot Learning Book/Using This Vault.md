# Using this vault as a working book

[[Home]] | [[Book Map]]

## Read, retrieve, and connect

Open [[Home]] as the table of contents. Follow chapter links in order initially, then use [[Notation and Glossary]] and [[Equation Reference]] for retrieval. Reading view renders the LaTeX equations and Mermaid diagrams. Collapsible answer callouts let you attempt an exercise before revealing its solution.

Use the local graph on a chapter to see nearby concepts and paper notes. The global graph includes your entire vault; filter it to the book and literature folders when you want a focused view. Graph edges are explicit wiki links, so adding a justified relationship improves the map. A dense graph by itself does not mean deeper understanding.

The curated [[Book Map]] Canvas provides a stable overview. The earlier [[Robot Learning Map]] still organizes the 20 papers.

## Notes that create useful work

Duplicate [[Reading Template]] for each full paper you read. Duplicate [[Experiment Template]] before running experiments. Use [[Concept Template]] for a difficult idea you can explain more clearly after studying, and [[Weekly Review Template]] once per week.

These are ordinary Markdown templates; no plugin installation is needed. If you later use Obsidian's built-in Templates command, point its template-folder setting at this book's Templates directory yourself or as a separate configuration task.

Frontmatter records type, status, and tags. [[Chapter Progress.base]] and [[Research Board.base]] use Obsidian's built-in Bases for editable views of those properties. The [[Research Dashboard]] also includes native search blocks for finding research ideas and experiments. [[Mastery Tracker]] is deliberately manual: checking a box requires evidence you can inspect.

## Suggested reading ritual

1. Predict what the chapter or paper will explain.
2. Write down the meaning of every unfamiliar symbol.
3. Work one small numerical example.
4. Describe one assumption that could fail on your SO-101.
5. Link the idea to a paper and a possible experiment.

## Provenance

Book explanations are original teaching notes with links to primary references. Existing paper summaries remain labeled as abstract-based. The scientific figures are reproducible analytic or synthetic illustrations, clearly labeled; no robot training or Jev benchmark result is claimed. Figure-generation code is in the book's Tools folder, with details in [[Figure Reproduction]].

Git records the vault. Review changes before committing; generated notes and figures are currently local working files. The work did not publish the vault or upload robot data.
