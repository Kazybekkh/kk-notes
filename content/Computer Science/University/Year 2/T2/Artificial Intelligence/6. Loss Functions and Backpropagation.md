## Loss Functions

The loss function measures how badly the AI system performed:

$$\ell(\vec{y}_{i}, \vec{y}_{i}^{*}) = \text{a "badness" score}$$

The total loss over the training set:

$$\mathcal{L} = \frac{1}{n} \sum_{i=1}^{n} \ell(\vec{y}_{i}, \vec{y}_{i}^{*})$$

## Binary Cross-Entropy (BCE)

For binary classification (output via [[5. Activation Functions|sigmoid]]):

$$\ell_{BCE}(\vec{y}_{i}, \vec{y}_{i}^{*}) = -y_i \log(y_{i}^{*}) - (1 - y_i) \log(1 - y_{i}^{*})$$

$$\mathcal{L}_{BCE} = \frac{1}{n} \sum_{i=1}^{n} \ell_{BCE}(\vec{y}_{i}, \vec{y}_{i}^{*})$$

## Categorical Cross-Entropy (CCE)

For multi-class classification (output via [[5. Activation Functions|softmax]]):

$$\ell_{CE}(\vec{y}_{i}, \vec{y}_{i}^{*}) = -\sum_{c=1}^{V} y_{ci} \log(y_{ci}^{*})$$

$$\mathcal{L}_{CE} = \frac{1}{n} \sum_{i=1}^{n} \ell_{CE}(\vec{y}_{i}, \vec{y}_{i}^{*})$$

## Mean Squared Error (MSE)

For regression (see also [[15. Regression and Text Classification with FCNs]]):

$$\ell_{MSE}(\vec{y}_{i}, \vec{y}_{i}^{*}) = \frac{1}{V} \sum_{c=1}^{V} (y_{ci} - y_{ci}^{*})^{2}$$

$$\mathcal{L}_{MSE} = \frac{1}{n} \sum_{i=1}^{n} \ell_{MSE}(\vec{y}_{i}, \vec{y}_{i}^{*})$$

## Summary: Loss + Output Activation Pairing

| Task | Output Activation | Loss Function |
|---|---|---|
| Binary classification | Sigmoid | Binary cross-entropy |
| Multi-class classification | Softmax | Categorical cross-entropy |
| Regression | Linear (none) | Mean squared error |

## Gradient Descent and Backpropagation

**Gradient** — indicates the direction and rate of steepest ascent of the error function. To minimise the loss, we move in the **opposite direction** of the gradient.

**Backpropagation** computes the gradient of the loss with respect to each weight using the **chain rule**.

**Weight update rule:**

$$W \leftarrow W - \alpha \cdot \nabla_W \mathcal{L}$$

where $\alpha$ is the learning rate.

## SGD vs Mini-Batch SGD

| | SGD | Mini-Batch SGD |
|---|---|---|
| **Samples per update** | 1 random sample | A batch of samples |
| **Gradient estimate** | Noisy | Smoother |
| **Speed** | Fast per step | More stable convergence |

**Training loop:** Input → Predict → Error → Backprop → Update → Repeat

## Dropout (Regularisation)

Dropout randomly drops (zeroes out) some neuron outputs during training with probability $p$. This prevents overfitting (see [[7. Evaluating ML Models]]) by making the model less sensitive to noise and more generic.

```python
model.add(Dropout(0.3))  # 30% dropout probability
```

## Optimisers

| Optimiser | Description |
|---|---|
| **SGD** | Basic stochastic gradient descent |
| **RMSprop** | Adapts learning rate per parameter |
| **Adam** | Combines momentum and adaptive learning rates; often the default choice |
